# The Excuse That Almost Works

A Python program that writes a single, almost believable excuse text — a gamer messaging their boss about a mandatory gas safety inspection during GTA 6 launch week, with one small slip ("mission") that nearly gives the game away.

## How to run

```sh
python3 main.py
```

The program writes the excuse line, exactly as-is, to `/output/entry.txt` (creating `/output` when needed) and prints nothing.
